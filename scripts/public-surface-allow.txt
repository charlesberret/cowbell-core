# One Python re per line. A match is removed from a candidate line, and the
# line is a hit only if a denylist pattern remains.
# Blank lines and lines starting with # are ignored.

# Fold count in cowbell.py ("FOLD-1 rows"), not an issue id.
\bFOLD-[0-9]+\b
# Encoding names, hash names, and advisory ids. Same shape as an issue id.
\bUTF-[0-9]+\b
\bSHA-[0-9]+\b
\bCVE(?:-[0-9]+)+\b
